# auditgym v2.0.0

Подключение по определениям проверок жюри от 20 ноября. Версии: пакет 2.0.0, генератор 0.3.0,
среда 1.1.0, оценщик 2.0.0, config 1.0.

- **`judge_adapter.py`** — `generate_episode`, `make_env`, `score_episode`. Как запустить: `docs/judge.md`.
- **Оценщик 2.0.0.** ID и валюта сравниваются точно; допуск 0 (у `fx_conversion` 1 из-за округления);
  неизвестный тип, валюта или ID — один FP, а не −1 за весь ответ; порядок среди равных совпадений
  как в определениях.
- **Среда 1.1.0.** Принимается самый большой допустимый ответ; 60 секунд считаются от начала `reset`;
  закрытый процесс запускается из любого скрипта.
- **Генератор 0.3.0.** `allocation_mode` выбирает пропущенное или частичное распределение. Записи и эталоны
  опубликованных эпизодов прежние.
- **`tests/judge/`** — C01–C20, D01–D20, matcher 1–20, M01–M12, P01–P20 через адаптер.
- Веб-интерфейс: светлая тема, отчёт в Word, понятные названия наборов.

Проверка: `make check` или
`docker build -t audit-rl-env . && docker run --rm --network none --cpus 2 --memory 4g audit-rl-env`.
Данные вымышлены, обучение весов не проводилось.
