# auditgym v1.0.0

Воспроизводимая среда синтетического финансового аудита с командными генератором,
AuditEnv и grader, четырьмя политиками, runner и приёмкой.

- Oracle, FlagAll, RandomExplorer(seed), Reconciler; train/eval и процессная оценка.
- JSONL-траектории, CSV-метрики, автоматическая проверка утечек.
- 320 приёмочных проверок seed, перестановок строк и смены ID дополнительно к
  тестам генератора, среды, оценщика, упаковки и интеграции.
- Финальный прогон на Linux/Python 3.11 и Docker без сети, с 2 CPU и 4 GiB.
- Wheel проверен после установки вне исходников; все 10 JSON-схем включены.

Вложения: wheel, архив исходников с отчётами, SHA256 и терминальное демо asciinema
на 135 секунд. manifest.json в ZIP перечисляет файлы и контрольные суммы,
фиксирует исходный commit и подтверждённую контейнерную проверку. Открытые
тестовые эпизоды и их эталоны входят в исходники; сырые Oracle-траектории из
рабочих прогонов автоматически не включаются.

Установка: `python -m pip install auditgym-1.0.0-py3-none-any.whl`.
Полные проверки выполняются из распакованной папки source после установки .[dev]:
`python -m auditgym.runner.validate --out runs/check --deadline 600`.

Версия пакета — 1.0.0; generator/env — 0.1.0, grader — 1.0.0, config — 1.0.
Обучение весов не проводилось. Данные искусственные, качество на них не является
подтверждением применимости к реальному аудиту. Cyberpunk-прототип остаётся
отдельным демо и пока не подключён к реальному backend.
