# Приёмка политик на командных AuditEnv и Grader

```sh
python -m auditgym.runner.validate --out runs/check --deadline 600
python -m auditgym.runner --episodes episodes/sample/sample_00 --out runs/sample
python -m auditgym.runner.leaks runs/sample/trajectories.jsonl
```

Используются реализации участников 2 и 3, без тестового matcher или альтернативной
среды. Преобразованные эпизоды записываются во временную папку и загружаются через
публичный reset(episode_dir=...). Версии и контракты: docs/env.md и docs/grader.md.

## 320 проверок

20 открытых selfcheck-эпизодов: 5 чистых, 5 со сценариями A/B, 10 смешанных.
Для Oracle, FlagAll, RandomExplorer и Reconciler проверяются четыре критерия:

1. Корректные действия, публичные существующие ID, лимит шагов, отсутствие утечек.
2. Повторная генерация по seed и точное совпадение траекторий; wall-clock время
   сравнивается отдельно и не является частью детерминированной траектории.
3. Перестановка строк invoices/payments/ledger и изменение порядка FX.
4. Смена ID с обновлением ссылок и обратным отображением для сравнения ответа.

Oracle и Reconciler обязаны сохранять смысл выводов и награду при преобразованиях.
У FlagAll и RandomExplorer выбор подмножества строк может изменить ответ; для них
проверяются корректность ID, завершение и повторяемость на одинаковом изменённом
входе. Изменения ответов/награды явно отражаются в details отчёта.

Дополнительная интеграционная проверка запускает все четыре политики в train и
eval, валидирует каждый шаг по командной trajectory_line.schema.json, проверяет
независимость наблюдений от приватной диагностики и обработку записей RandomExplorer.
При тайм-ауте до действия используются фактические step/inspection_steps среды.

## Утечки

Runner применяет опубликованный leak_scan среды вместе с дополнительными
проверками вложенных ключей, строк, приватных ID, seed-присваиваний, локальных
путей, stack trace и канареек. Проверяются reset/step observation, info и actions;
JSONL перечитывается с диска перед записью итогового leak_report.json.
Финальные оценки берутся из grade_log, но matches, missed_issue_ids,
finding_reasons и errors туда не копируются.

Oracle может отправить правильный канонический ответ как привилегированный агент,
но не освобождается от сканирования. Его траектории содержат правильные ответы
и не предназначены для обучения или наблюдений других политик.

Обычный runner использует настоящий grader. `--dry-run` — отдельная диагностика
транспорта без метрик, с совместимостью старых тестовых envelopes.

Сканер проверяет известные маркеры и не является доказательством отсутствия всех
семантических утечек или песочницей для произвольного Python. Набор selfcheck
открыт и не заменяет закрытые эпизоды жюри. Качество на синтетике не доказывает
пригодность для реального финансового аудита.
