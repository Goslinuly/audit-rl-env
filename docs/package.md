# Пакет сдачи и проверка установленного модуля

JSON-схемы включены в wheel как ресурсы `auditgym.schemas`. Публичные копии
в корневой папке `schemas/` сохранены; тест проверяет их совпадение с пакетными.
Версии инструментов сборки закреплены в pyproject.toml.

```sh
python -m pip wheel --no-deps --wheel-dir runs/release-build .
python tools/check_wheel.py runs/release-build/auditgym-0.2.0-py3-none-any.whl
```

Проверка устанавливает wheel во временную папку и запускает код за пределами
репозитория. Проверяются импорт именно установленного модуля, все 10 схем, награда
Oracle и реальный прогон Reconciler. Зависимости должны быть установлены заранее.
В CI эта проверка выполняется после полного прогона тестов.

## Архив кандидата

Перед упаковкой завершите правки исходников и выполните полный прогон:

```sh
python -m auditgym.runner.validate --out runs/package-validation --deadline 600
python -m auditgym.runner.bundle --out runs/submission/auditgym-0.2.0-candidate.zip --validation runs/package-validation --demo docs/demo/participant4.cast --wheel runs/release-build/auditgym-0.2.0-py3-none-any.whl
python -m auditgym.runner.bundle --verify runs/submission/auditgym-0.2.0-candidate.zip
```

Отчёт проверки связан с SHA256 исходных файлов, включая незакоммиченные изменения.
Если код или документация изменились после проверки, упаковка останавливается.
Снимок также работает без .git — например, внутри Docker. В таком случае
служебные каталоги, локальные настройки и результаты прогонов исключаются явно.

Архив содержит source/, установленный пакет в packages/ и выбранные evidence/:
итоги проверки, приёмку, JUnit и терминальное демо. В исходники входят
опубликованные тестовые эпизоды и их эталоны. Сырые Oracle-траектории из runs/
в пакет автоматически не добавляются.

manifest.json перечисляет файлы, размеры и SHA256. Рядом создаётся контрольная
сумма всего ZIP. Проверка архива отвергает изменение содержимого, лишние/повторные
файлы и небезопасные пути. Это контроль целостности, а не криптографическая подпись.

Метаданные честно указывают статус candidate_unverified_container. Создание пакета
не означает релиз, успешный Docker-прогон, коммит или публикацию на GitHub.
