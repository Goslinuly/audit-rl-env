# Подключённый cyberpunk-интерфейс

Запуск: `python -m pip install -e ".[dev]"`, затем `python ui/server.py`.
Откройте http://localhost:8000; сервер учитывает переменную окружения `PORT`.

`GET /api/episodes`, `/api/episodes/<split>/<name>`, `/api/presets` и
`/api/generate?preset=...&seed=...` сохранены без изменения форматов.
`POST /api/run` принимает, например:

```json
{"source":{"split":"sample","name":"sample_00"},"policy":"Reconciler","seed":42}
```

Для сгенерированного эпизода: `source: {"preset":"mixed_small","seed":42}`.
Ответ содержит `metrics`, `trajectory`, `findings`, `source`, `policy_seed` и
`privileged`. Каждый запрос создаёт отдельную политику и AuditEnv с лимитом 100
шагов. Используется существующий runner с проверкой утечек; в траектории нет
диагностики grader. Oracle отдельно получает эталон и помечается как privileged.
Доступны только опубликованные sample/train/dev и перечисленные пресеты.
Пути файлов от клиента не принимаются. Ограничены размер запроса и число
одновременных прогонов. Публичный обозреватель не является закрытым eval-сервисом.

Суммы — реальные целые minor units с exponent из manifest. Разные валюты
не складываются в одну сумму. График показывает дебетовый оборот за четыре
равные части периода эпизода. Выводы появляются после запуска политики,
а метрики сравнения рассчитываются только по выполненным прогонам.

Каталог, имена компаний и подтверждения локальны для браузера. Серверные
эпизоды не меняются при переименовании или удалении. Генерация и изменение
пресета/seed вызывают командный генератор. После обновления страницы результаты
прогонов нужно получить заново; для сохранения предусмотрено скачивание отчётов.
Ручная отметка не является оценкой grader и указана в отчёте отдельно.

## Проверки

Python HTTP-тесты: `python -m pytest tests/test_web_workspace.py`.
Для браузерного набора нужны Node.js и Playwright:

```bash
npm install --no-audit --no-fund --prefix runs/ui-qa playwright@1.62.1
./runs/ui-qa/node_modules/.bin/playwright install chromium
NODE_PATH="$PWD/runs/ui-qa/node_modules" python tools/check_web_ui.py
```

Последняя команда приведена для bash. В PowerShell задайте
`$env:NODE_PATH="$PWD/runs/ui-qa/node_modules"`, затем выполните
`python tools/check_web_ui.py`. Для установленного Chrome можно задать
`CHROME_PATH` с путём к исполняемому файлу. `NODE_BIN` позволяет указать путь к Node.
Проверки запускают временный сервер, проверяют все шесть страниц, реальные
политики, генерацию, редактирование, подтверждения, скачивание и размеры
320/768/1440 px. Результат — `runs/web-ui-qa.json`, снимок — `runs/web-ui-qa.png`.

Railway не нужен для локального запуска. Сохранённые `railway.json` и
`ui/Dockerfile` могут использоваться владельцем сервиса позднее.
